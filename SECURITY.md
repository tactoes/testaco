# Security policy

To report security vulnerabilities, please use GitHub Security Advisories for this repository: https://docs.github.com/en/code-security/security-advisories.

Steps:
1. Open a security advisory in this repository (Owners/Maintainers can create an advisory).
2. Provide reproduction steps, impact, and any available fixes or mitigations.
3. The maintainer(s) will coordinate disclosure and patching.

Do NOT open public Issues for security-sensitive reports.
